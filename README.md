# Xiaomi 15 Pro (haotian)

Device configuration for building LineageOS-based Android distributions for
the Xiaomi 15 Pro.

This tree targets the `lineage-23.2`/Android 16 generation and uses the stock
kernel artifacts from `device/xiaomi/haotian-kernel`.

The initial device bring-up was based on work by
[lolipuru](https://github.com/lolipuru/device_xiaomi_haotian) and
[Rep1ace](https://github.com/rep1ace/device_xiaomi_haotian).
